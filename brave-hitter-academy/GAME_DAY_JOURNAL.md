# BRAVE HITTER ACADEMY — GAME DAY JOURNAL

This file is authoritative for the Game Day Journal.

## LOCKED STRUCTURE
- Exactly 20 game entries
- Exactly 2 pages per game
- 40 pages total
- Games 1–20 repeat the same two-page template
- Designed for BEFORE and AFTER the game
- Not intended for filling out during the game or in the dugout
- No tournament-specific or championship-specific variants
- No page numbers
- Maintain generous writing space
